# Versioning references

The existing policy, rollout/governance/checklist and migration-plan templates
are retained as generic reference documents. They do not report the app's current
feature/schema/release status. See [release process](../Project%20Documents%20Templates/RELEASE_PROCESS.md),
[current evidence](../ALPHA_STATUS.md) and the source history.

Current source candidate is 0.1.0-alpha.1, schema 18 (2026-11-23), with no published
release/tag. Synchronizing the review branch does not perform a version bump,
merge main or authorize publication. Applied migrations remain immutable.
